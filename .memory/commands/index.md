# Commands

## Available Workflows

| Command | File | When to Use |
|---------|------|------------|
| New Feature | `commands/new-feature.md` | Adding a new tracking feature, page, or AI capability |
| Fix Bug | `commands/fix-bug.md` | Investigating and fixing broken functionality |
| Deploy | `commands/deploy.md` | Merging a sprint to main and deploying to Vercel |

## Actions

- **Repeated a workflow 3+ times without a command file?** Create one.
- **Workflow changed?** Update the command file.
