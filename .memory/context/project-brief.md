# Project Brief

## What It Is

**Arogyamandiram** (Sanskrit: "Temple of Good Health") is a premium health & wellness tracking web application built for Indian users. It is a full-stack Next.js 14 app that lets users track calories, food, water, weight, workouts, and sleep — with AI-powered insights and a gamification layer (streaks, badges, XP, levels).

## Who It's For

Health-conscious individuals in India looking for an integrated, culturally relevant alternative to generic calorie trackers. The built-in database of 150+ Indian foods (curries, dals, breads, sweets, snacks, beverages, etc.) differentiates it from global apps.

## What Problems It Solves

- No good Indian-food calorie database in mainstream trackers
- Fragmented tools (separate apps for food, water, workouts, sleep)
- Lack of AI-generated insights tailored to Indian dietary patterns
- No gamification to keep users engaged with health habits

## Core Features

| Feature | Description |
|---------|-------------|
| Food Logger | Search 150+ Indian foods + Edamam API fallback; custom food entries; AI natural-language parsing |
| Water Tracker | Animated glass visualization, quick-add buttons, daily targets |
| Weight Journal | Trend charts (7D–1Y), BMI calculator, history table |
| Workout Planner | 50+ preset exercises, calorie burn estimation, AI workout logging |
| Sleep Tracker | Bedtime/wake time, duration, quality rating (1–5 stars) |
| AI Insights | GPT-4o-mini analysis by period (yesterday/week/month/year) |
| Gamification | Streaks (8 types), badges, XP, leveling system |
| Achievements | Badge collection grid, streak overview, personal records |
| Onboarding | 4-step wizard (height, weight, activity level, goal) with auto-calculated targets |

## Project Status (as of 2026-03-26)

Active development. Core features are stable. Current sprint (`feature/dev-01-uiux-sprint-march-8th`) is focused on UI/UX standardization — card styling, gradients, color palette consolidation, accessibility improvements.
